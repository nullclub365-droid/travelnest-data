# travelnest-data

Public, read-only data for the TravelNest app: `index.json` (the city list, with a
content version per city) and one gzipped city pack per city (`<slug>.json.gz`).

Served by GitHub Pages at https://nullclub365-droid.github.io/travelnest-data/ and
downloaded by the app, so new cities and fixes ship without an app update.

Generated by `tools/build_all.py` and `tools/publish_packs.py` in the app repo; don't
edit by hand. City facts (fares, hours, phone numbers) are compiled for travellers and
should be verified against official sources.

Map data © OpenStreetMap contributors (ODbL).
